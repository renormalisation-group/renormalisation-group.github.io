# Source artwork

Downloaded 18 October 2026. Commons marks the design as public domain (PD-ineligible).

The animation uses the two original symbol paths, with the original group translation
and uniform scaling. Background, colours and unused metadata are not rendered.
The visible guide and sampled bird routes derive from the same SVG contours.
